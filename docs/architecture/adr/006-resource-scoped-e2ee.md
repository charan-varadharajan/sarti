# ADR-006: Resource-scoped end-to-end encryption

- Status: Accepted; protocol unresolved
- Date: 2026-10-11

Encrypt family content end to end between authorized devices with resource-scoped
access. The server cannot decrypt it. Algorithms, libraries, envelope format,
authenticated metadata, key hierarchy, distribution, rotation, and revocation
are deliberately unresolved and require approval before E2EE implementation.
