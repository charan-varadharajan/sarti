# Sarti

Sarti is a privacy-first AI family organizer: **Your family's wise companion.**

The project is in Stage 1. This repository currently contains the approved product,
architecture, security, testing, and engineering baseline. Application code begins
only after the Stage 1 review recorded in `docs/STATUS.md`.

## Start here

1. Read `AGENTS.md`.
2. Read the mandatory documents linked from it.
3. Check `docs/STATUS.md` for the current stage and open decisions.

No production hosting provider, cryptographic wire format, database schema, or
external email provider has been selected yet.
